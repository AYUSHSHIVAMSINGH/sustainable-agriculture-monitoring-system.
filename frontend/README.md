# Frontend - Sustainable Agriculture Monitoring System

Modern, responsive React + Vite dashboard for the Operating Systems PBL project at NIET.

---

## Visual Theme
Designed with an agricultural green, white, and light-neutral palette for clean aesthetics and high readability.

---

## Navigation Sections
* **Dashboard:** Project overview, architecture summary, and real-time backend health monitoring.
* **Sensor Monitoring:** I/O streams and telemetry ingestion.
* **CPU Scheduling:** Process scheduling algorithms (FCFS, SJF, RR) applied to agricultural priority jobs.
* **Process Synchronization:** Mutex locks and semaphores for shared irrigation equipment.
* **Deadlock Management:** Banker's algorithm for shared water/chemical pump allocation.
* **Memory Management:** Page replacement algorithms (FIFO, LRU) for telemetry buffering.

## Setup & Running Instructions

### Step 1: Open terminal in the `frontend` folder
```powershell
cd "C:\Users\Ayush Shivam Singh\.gemini\antigravity\scratch\sustainable-agri-monitor\frontend"
```

### Step 2: Install dependencies
```powershell
npm install
```

### Step 3: Run the development server
```powershell
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## Building for Production
To test or create an optimized production build:
```powershell
npm run build
```
The output files will be created in `frontend/dist/`.
