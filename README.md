# Sustainable Agriculture Monitoring System

**Course:** Operating Systems Project-Based Learning (PBL)  
**Institution:** Noida Institute of Engineering and Technology (NIET)

---

## 1. Project Overview
The **Sustainable Agriculture Monitoring System** is a software system designed to track and manage agricultural parameters (such as soil moisture, temperature, humidity, and irrigation status). 

For an Operating Systems PBL, the system serves as a practical demonstration of core OS concepts:
* **Process & Concurrency Management:** Managing background data collection and asynchronous requests.
* **Inter-Process Communication & I/O:** Reading sensor data streams and updating persistent storage.
* **Resource Optimization:** Efficient memory and CPU utilization for real-time monitoring and alerting.

---

## 2. Technology Stack
* **Frontend:** React + Vite (Modern, fast, and responsive user interface)
* **Backend:** Python FastAPI (High-performance, asynchronous REST API)
* **Database:** SQLite (Lightweight, serverless relational database)
